## 1. 目的 (Repository Purpose)

本リポジトリは、過去の AIOS モノレポ構造、エージェントランタイム、AI社員運用体制から完全に分離・独立した、**純粋な POSTING MAP スタンドアロン商品リポジトリ** の公式出発点（Baseline）です。

以後のすべての機能追加、リファクタリング、および新バージョン開発（v1.1, v2.0...）は、本 `v1.0.0` リリースを出発点として行われます。

---

## 2. SSOT (Single Source of Truth) の定義

- **コードベース & 資産 SSOT**:
  - 本リポジトリ (`K-IWASA-MK/posting-map`) を唯一の正本として開発・管理。
- **MIE-03 住所マスターデータ SSOT**:
  - 参照パス: `data/MIE03_ADDRESS_MASTER_858.csv` (確定データ総数: ヘッダー1行 ＋ 実データ858件)

## 3. ディレクトリ構成 (5-Directory Freeze Rule)

本リポジトリは Repository Freeze v1.0 Rules に基づき、以下の **5 ディレクトリ** に永久固定されています。

```text
POSTING MAP Root
├── active/      # 唯一の本番コードベース (GAS, UI, Business Layer, Platform, Runtime)
├── data/        # SSOT マスターデータ & 空間バウンダリデータ
├── docs/        # 仕様書・アーキテクチャ・監査レポート・ガバナンス文書
├── scripts/     # 開発・検証・運用補助スクリプト
└── tests/       # テストコード (Unit & Integration)
```

---

## 4. 採用アーキテクチャ (Adopted Architecture)

1. **Business Domain Separation**:
   - `active/business/{domain}/` 配下に領域別（`area`, `flyer`, `gps`, `staff`, `distribution`）ドメインサービスを配置。
   - `v2_api.js` から Facade パターン経由でビジネスロジックを呼び出す疎結合構成。
2. **Platform & Infrastructure Layer**:
   - LINE LIFF 統合プラットフォーム (`active/platform/`)
   - Google Spreadsheet / Drive データアクセサー (`active/infrastructure/`)
3. **Runtime Layer**:
   - POSTING MAP アプリ本体のアプリケーションランタイム (`active/runtime/`)

---

## 5. ガバナンス方針 (Governance Policy)

1. **GAS デプロイ運用ルール (SOP)**:
   - コード変更後は `clasp push` および既存 Deployment ID への `clasp deploy` を必須とし、Web App URL を不必要に変更しない。
2. **起動時非再帰ルール**:
   - アプリ起動時の循環参照・排他デッドロック防止のため、`loadData()` の再帰呼び出しを厳禁とする。
3. **Anti-AIOS 混入防止ルール**:
   - ルート直下への `/agents`, `/skills`, `/knowledge`, `/AI社員`, `/runtime` などの AIOS 資産の作成・復元を永久禁止する。
