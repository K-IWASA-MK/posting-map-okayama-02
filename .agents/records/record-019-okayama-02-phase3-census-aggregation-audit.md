## 6. 正式採用の実施記録

1. スクリプト `scripts/generate-boundaries-geojson.py` を作成。
2. Candidate GeoJSON (`scratch/candidate_boundaries.geojson`) を生成。
3. `BOUNDARIES_FILE=scratch/candidate_boundaries.geojson node scripts/validate-district-data-gate.mjs` を実行し、全8ルール ALL PASS を確認。
4. 正式正本 `data/boundaries.geojson` へ Candidate をコピー・昇格。
5. `node scripts/validate-district-data-gate.mjs` を再実行し、本番ファイルで 8/8 PASS を確認完了。

全508件の個別追跡データは `scratch/phase3_508_audit_table.json` に永久保存されており、各rowIdについて「どのe-Stat KEY_CODE、どのS_NAMEからその人口・世帯数・ジオメトリが導出されたか」を1件単位で即座に証明できる状態を確立した。
