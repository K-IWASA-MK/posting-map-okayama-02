## 3. 重要分析：第49回（2021年）区割り改定影響の完全解明

### 背景
令和4年（2022年）の公職選挙法改正（10増10減）により、岡山県の小選挙区区割りが変更された。
- **旧第2区（第49回まで）**: 岡山市北区第二（御津・建部等）、岡山市中区、岡山市東区第一（瀬戸地区除く）、岡山市南区第二（灘崎・児島湾沿岸等）、玉野市、瀬戸内市
- **現行第2区（第50回以降）**: **岡山市中区、岡山市東区（全域）、岡山市南区（全域）、玉野市、瀬戸内市**

### 第49回の2種類の集計値
1. **当時の「岡山2区」の公表確定値**:
   - 当日有権者数: 289,071人
   - 投票者数: 145,751人
   - **投票率: 50.42%**
2. **現行岡山2区を構成する自治体区域（中区・東区全域・南区全域・玉野市・瀬戸内市）で再集計した値**:
   - 岡山市中区: 有権者 120,818人 / 投票者 58,874人
   - 岡山市東区全域: 有権者 78,596人 / 投票者 38,946人
   - 岡山市南区全域: 有権者 138,929人 / 投票者 63,444人
   - 玉野市: 有権者 49,667人 / 投票者 26,710人
   - 瀬戸内市: 有権者 31,268人 / 投票者 17,220人
   - **合計有権者数: 419,278人**
   - **合計投票者数: 205,194人**
   - **再集計投票率: 48.94%** (205,194 ÷ 419,278 = 48.94008...%)

※Dashboardにおける時系列比較（過去3回の推移）においては、同一の行政区域（現在のOKAYAMA-02管轄全域）を対象とするため、**再集計値 48.94%** を採用するのが統計的一貫性において最も正確である。なお、旧選挙区ベースの **50.42%** も公式記録として注記・保持する。
